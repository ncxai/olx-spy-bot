# OLX Spy Bot 24/7 (Telegram-бот для мониторинга olx.uz)

Умный Telegram-бот [@parserolxuzb_bot](https://t.me/parserolxuzb_bot) для круглосуточного мониторинга свежих объявлений на [olx.uz](https://www.olx.uz).

---

## 🚀 Все возможности бота

### 1. 🖼 Карточки товаров с фото и кнопками
* Бот извлекает реальные фотографии товаров в высоком разрешении (`1000x700`) и присылает карточку с фото.
* Под каждой карточкой есть кнопки:
  * `[ 🔗 Открыть на OLX ]` — прямой переход на объявление.
  * `[ ⭐ В избранное ]` — сохранение в персональный список избранного.

### 2. 🔥 Детектор суперцен (Smart Deal)
* Бот автоматически рассчитывает медианную цену на товар в поиске.
* Если цена объявления **на 20% и более ниже рынка**, бот помечает его плашкой:
  `🔥 ВЫГОДНАЯ СДЕЛКА! На ~35% ниже средней цены!`

### 3. 📋 Мульти-мониторинг (несколько поисков одновременно)
* Вы можете отслеживать сколько угодно товаров параллельно:
  * Например: `iPhone 13 Pro` в Карши + `PlayStation 5` в Ташкенте + `MacBook M1` по всему Узбекистану.
* **`/tasks`** (или `/my_tasks`) — список ваших активных поисков с кнопками удаления.
* **`/add <товар>`** (или просто отправка текста) — добавить новый товар на отслеживание.

### 4. ⭐ Избранное (Закладки)
* **`/favorites`** (или `/fav`) — просмотр всех сохраненных объявлений с кнопками перехода и удаления.

### 5. 🎯 Умные фильтры
* **`/city`** — выбор любого города/области Узбекистана или всей страны.
* **`/price`** — фильтрация по цене (готовые диапазоны кнопками или команды вида `/price 1000000 5000000`).
* **`/seller`** — выбор продавца: `Частные лица 👤`, `Бизнес / Магазины 🏢` или `Все 🌐`.
* **`/stop_words`** — минус-слова (исключение `копия`, `чехол`, `запчасти`, `обмен`, `реплика` и т.д.).
* **`/sort`** — сортировка: `Сначала новые (по дате)` или `Сначала дешевые`.
* **`/interval`** — персональная частота проверки (`2 мин`, `5 мин`, `10 мин`...).

### 6. ⚙️ Статус и управление
* **`/status`** — панель управления текущим поиском со всеми фильтрами.
* **`/stop`** — остановка мониторинга и удаление задач.
